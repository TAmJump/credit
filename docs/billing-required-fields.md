# 請求業務 棚卸し ＆ 業態別 必須記載項目チェックリスト

CarePay の請求機能が「医療・介護で本当に通用するか」を、現状把握と法令要件の両面で固めた設計図。
最終更新：2026-05-29

---

## A. 現状の棚卸し（いま CarePay にあるもの）

### 発行できる書類（業態テンプレート 6種）
| 業態 | 発行物 | 法令根拠（note） |
|---|---|---|
| 医療（保険診療） | 請求書／領収証（区分付）／医療費明細書 | 療担規則第5条の2・厚労省通知 |
| 医療（自費・自由診療） | 請求書（インボイス対応）／領収証 | インボイス制度 |
| 介護保険施設（老健・介護医療院・特養） | 請求書／領収証（医療費控除対応・区分付）／医療費控除対象額明細 | 厚労省通知・国税庁 No.1125 |
| 介護保険サービス（訪問・通所） | 利用料請求書／領収証／サービス提供明細 | 介護給付費請求書様式 |
| 居宅サービス（医療費控除対応） | 請求書／領収証（居宅・医療費控除対応） | 国税庁 No.1127・通達 |
| 福祉サービス（障害福祉等） | 請求書／領収証 | 自立支援給付の区分 |

### 既にある機能
- 適格請求書 登録番号（T+13桁）の形式検証
- 税率区分（10%／8%／非課税）の自動表示
- 電子発行（タイムスタンプ＋ハッシュ署名・QR検証）
- 債権管理（状態一覧・未収・経過日数・エージング）
- 督促（SMS→文書→電話の3段階）
- 再請求 SMS、CSV エクスポート

### まだ弱い／未実装（次の開発対象）
- [ ] 領収証の「**区分構造**」が法定様式を満たしているかの作り込み（後述 B-1）
- [ ] 介護の「**医療費控除対象額**」の自動計算（特養＝1/2、老健等＝全額 など業態で式が違う）
- [ ] 紙対応者の管理（Web登録できない人を同じ画面で扱う）
- [ ] 電子交付の動線（発送業務を消す：SMS/メールでの交付＋開封・受領記録）
- [ ] 未収の自動判定・督促の自動スケジュール（現在は手動トリガー）

## B. 業態別 必須記載項目（法令ベース）

### B-1. 医療（保険診療）の領収証・明細書 ★最重要
**根拠：療担規則第5条の2 ／ 厚労省通知（令和6年3月5日 保発0305第11号）**

領収証は「簡易レシート不可」「個別の費用ごとに区分」「所定様式」「無償交付」が義務。
レセプト電子請求が義務の医療機関等は、明細書（個別の診療報酬算定項目が分かるもの）も無償交付。
（令和6年6月1日からは指定訪問看護事業者にも明細書交付義務が追加）

**領収証 必須記載：**
- [ ] 発行年月日／患者氏名／医療機関名・所在地
- [ ] 費用区分ごとの金額（**初・再診料／医学管理／検査／画像診断／投薬／注射／処置／入院 等、診療報酬点数表の各部単位**）
- [ ] 保険外費用がある場合は、その個別の名称・金額を区分して記載
- [ ] 負担割合・一部負担金額、合計額
- [ ] 「明細書を無償交付する旨」の院内掲示の運用（アプリ外だが案内に含める）

**明細書 必須記載：**
- [ ] 個別の診療報酬点数の算定項目（投薬等の薬剤・保険医療材料の名称を含む）
- [ ] 発行年月日等
- [ ] 標準様式（別紙様式5）または診療報酬明細書様式を活用

### B-2. 医療（自費・自由診療）
**根拠：インボイス制度（適格請求書）**
- [ ] 適格請求書発行事業者の**登録番号（T+13桁）**
- [ ] 取引年月日／取引内容／税率ごとに区分した対価の額・適用税率
- [ ] **税率ごとに区分した消費税額**
- [ ] 交付を受ける者の氏名・名称、発行者の氏名・名称
- （自費診療は課税。保険診療部分と混在する場合は区分）

### B-3. 介護保険施設（特養・老健・介護医療院）
**根拠：厚労省通知 ／ 国税庁 No.1125**
- [ ] 施設名に種別を明記（「介護老人保健施設」「介護医療院」等）
- [ ] 利用料の区分：**介護サービス費（自己負担1〜3割）／食費／居住費／日常生活費**
- [ ] **医療費控除対象額の記載**（無いと利用者が控除を受けられない）
  - 特養（指定介護老人福祉施設）：（介護サービス費自己負担＋食費・居住費）**の1/2**
  - 老健・介護医療院・療養型：介護サービス費自己負担＋食費・居住費**の全額**
- [ ] 日常生活費（理美容代等）は控除対象外として区分

### B-4. 介護保険サービス（訪問・通所）／居宅
**根拠：国税庁 No.1127 ／ 平成12年通達**
- [ ] サービスごとの単位数・利用者負担額・保険請求額・公費分の区分
- [ ] **居宅サービス計画を作成した介護支援事業者名**
- [ ] **医療費控除の対象となる金額**（医療系サービス＝訪問看護・訪問リハ・居宅療養管理指導・通所リハ・短期入所療養介護 等が対象。福祉系は医療系と併用時のみ等の条件）
- [ ] おむつ代等は「おむつ使用証明書」等の別要件あり（案内に含める）

### B-5. 福祉サービス（障害福祉等）
- [ ] 自立支援給付分／利用者負担分／実費分の区分
- [ ] 指定事業所番号、サービス種別

## C. 発送業務を消す「電子交付」動線（設計方針）
- 発行 → その場で PDF 化 → **SMS／メールのリンクで交付**（郵送ゼロ）
- 改ざん防止：タイムスタンプ＋ハッシュ署名、QR でオンライン検証（実装済みの仕組みを踏襲）
- **受領記録**：開封・ダウンロードの記録を残す（「交付した」証跡）
- 紙が必要な人：PDF を施設で印刷して窓口交付／郵送も選べる（同じ画面で管理）
- 控除用：年間分をまとめて再発行・一括ダウンロード（確定申告期の需要）

## D. 紙対応者も含めた一元管理（設計方針）
- 登録方法に関わらず1画面で：Web登録済み／紙登録済み／未登録 を色分け
- 紙の人も請求・発行・未収管理は同じフローに乗せる（振替実行だけ収納代行の紙受付）
- 「キャッシュカードが無い少数」はアナログ運用フラグを立てて例外管理

---

## E. 注意（共通）
- 社会保険診療・介護保険サービスは**消費税 非課税**。インボイスの税額記載対象は自費（課税）取引。
- 様式・控除の計算式・対象サービスは改定がある。**毎年の制度改正で要見直し**（特に介護報酬改定・診療報酬改定の年）。
- 最終的な様式適合は、各事業者の所轄（地方厚生局・自治体）の指導に従う。CarePay はテンプレを提供するが、最終責任は発行事業者。
