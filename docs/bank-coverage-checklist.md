# 収納代行の「銀行カバレッジ」比較と商談チェックリスト

CarePay は口座振替の裏側を収納代行に借りる。だから「ほとんどの銀行で登録できるか」は、契約する収納代行が決める。本書は、銀行カバレッジを軸に候補を比較し、商談で必ず確認する項目をまとめたもの。

最終更新：2026-05-29
（手数料・対応行数・条件は改定が多い。商談前に必ず各社の最新一次情報で更新すること。）

---

## まず仕組み（なぜ収納代行で決まるのか）

Web口座振替は「収納代行のサイトで利用者が自分の銀行を選び、銀行側の本人認証（キャッシュカード暗証番号・生年月日など）で登録が完結する」流れ。紙の依頼書だと口座登録に約1〜2か月かかるところを、リアルタイムに短縮できる。

つまり登録できる銀行の範囲は「その収納代行が、どの金融機関のWeb口座振替受付とつながっているか」で決まる。CarePay 単体では増減できない。ここが選定の核心。

---

## カバレッジの考え方（医療・介護で効く順）

医療・介護の利用者・支払者（家族）は高齢者が多く、口座の傾向が一般ECと違う。優先度はこの順。

1. **ゆうちょ銀行** … 高齢者の口座保有率が非常に高い。最優先。ただし方式により利用者側にもゆうちょ口座要件などがあるため要確認。
2. **地方銀行・第二地銀** … 地域密着の施設では主力。地元行が対象かどうかで成否が変わる。
3. **信用金庫・信用組合・JAバンク** … 地方ほど比率が上がる。カバー差が出やすい弱点ゾーン。
4. **都市銀行（三菱UFJ・三井住友・みずほ・りそな）** … ほぼ全社対応。差は付きにくい。
5. **ネット銀行（楽天・住信SBI・PayPay 等）** … 対応がまちまち。個人/法人で扱いが分かれることも。

「主要行はほぼ網羅」は多くの収納代行で言える。差が出るのは 3（信金・信組・JA）と 5（ネット銀行）、そして 1 の利用条件。ここを商談で潰す。

## 候補比較（カバレッジ視点・要一次確認）

| 収納代行 | 立ち位置 | カバレッジ傾向 | 確認ポイント |
|---|---|---|---|
| アプラス（SBI新生銀行G） | 大手・信販系 | 都銀・地銀・ゆうちょまで広い実績 | 信金/信組/JAの網羅、Web受付の対応行数 |
| 三菱UFJファクター | 銀行系 | 安定して広い | 同上。審査期間と最低件数 |
| ゼウス | 決済総合 | ゆうちょ・都銀・主要地銀（個人）。法人はネット銀行中心 | 法人口座の扱い、地銀の具体名 |
| DSK（電算システム） | 収納総合 | 口振＋コンビニに強い | Web口振の対応行リスト |
| 大阪ガスファイナンス | 集金代行 | 公共料金系の実績。Web受付は別表 | 「Web口座振替受付」対応行を別途要請 |
| 月額パンダ | 小口サブスク型 | Web口振対応・小口向け | 対応行数、ゆうちょ可否 |
| サブスクペイ（ROBOT PAYMENT） | サブスク課金 | API連携軽い | 対応行リスト、入金サイクル |

※ ゆうちょは方式（収納機関受付／金融機関受付／Web受付）で利用条件が変わる。Web受付では利用者側にもゆうちょ口座が要る場合がある等、必ず方式まで確認する。

## 商談チェックリスト（各社に必ず聞く）

### A. カバレッジ（最重要）
- [ ] **Web口座振替で登録できる金融機関リスト**（最新版）を出してもらう
- [ ] そのうち **ゆうちょ銀行**は対応か。利用者側の口座要件・方式は？
- [ ] **地方銀行・第二地銀**は何行対応か（導入先の地元行が入っているか名指しで確認）
- [ ] **信用金庫・信用組合・JAバンク**の対応範囲（ここが弱点になりやすい）
- [ ] **ネット銀行**（楽天・住信SBI・PayPay 等）の個人/法人それぞれの可否
- [ ] Web受付に**非対応の銀行**はどこか（紙でフォローできるか）

### B. 登録体験（現場の手間）
- [ ] 利用者の登録は**通帳・銀行印なし・スマホ完結**か
- [ ] 本人認証の方式（キャッシュカード暗証番号／生年月日 等）
- [ ] 登録から**振替開始までの日数**（締日→初回振替）
- [ ] 登録失敗・差し戻し時の再手続きフロー

### C. お金まわり（CarePayは触れない前提）
- [ ] 入金は**施設名義の口座**に直接入るか（CarePayを経由しない構成にできるか）
- [ ] 振替日から施設入金までの**入金サイクル**
- [ ] **1件あたり手数料・初期費用・月額・最低件数**（相場：1件 約100円〜、最安85円前後）
- [ ] 再振替（残高不足時の再トライ）の可否と費用

### D. データ連携（CarePayへ取り込む）
- [ ] 請求データの**受け渡し形式**（CSV／API）
- [ ] 振替結果・未収データの**返却形式とタイミング**
- [ ] CarePay標準フォーマットへ正規化できるか（収納代行を将来差し替えられるように）

### E. 審査・コンプラ
- [ ] 審査期間（通常2〜3週間、導入まで約1か月が目安）
- [ ] 医療・介護の業種で審査が通るか、必要書類
- [ ] 取扱不可の業種・課金内容の有無

## サイト表現のルール（誇張しない）

- ❌「すべての銀行で使えます」→ 言い切らない。
- ⭕「主要な金融機関に対応（ゆうちょ・都市銀行・地方銀行など）。対応行は順次拡大」
- ⭕「対応していない金融機関は、紙の手続きでフォロー」
- カバレッジは収納代行に依存するため、確定するのは契約後。サイトでは「主要行対応」までに留め、具体名や“全行”は出さない。

## 次アクション
1. 主軸候補2社（アプラス・UFJファクター）へ **A. カバレッジ**のリストを請求。
2. 導入先の所在地に合わせ、**地元の地銀・信金**が対応行に入っているか名指しで照合。
3. ゆうちょの方式・利用条件を確定（高齢利用者が多いため最重要）。
4. 確定したカバレッジ範囲に基づき、サイトの「対応金融機関」表記を更新。
