# CarePay Register（口座振替・契約／請求ハブ デモ）

介護施設向けの「契約・同意・家族導線・未収管理」を一元化する画面デモです。
決済会社そのものではなく、口座振替（収納代行）・Square・振込などの **上に乗る**
契約・請求ハブとしての画面イメージを確認するためのものです。

## 画面構成（単一ページ・3ビュー切替）
1. **施設 管理画面** … ダッシュボード／入居者ステータス一覧／フィルタ／入居登録モーダル
2. **家族 登録フロー** … 内容確認 → 電子同意 → 署名 → 支払い方法選択 →（カード登録）→ 完了
3. **未収 → 再請求SMS** … 携帯モックへのSMS演出と回収ステータスのタイムライン

## デモの注意
Square決済・SMS送信・収納代行連携は **動作しないモック演出** です。
本番化にはAPIキー・サーバー（Worker等）が必要です。

## アイコン／画像
`assets/img/` に画像を置くと反映されます（詳細は `assets/img/README.txt`）。
画像が無い場合は絵文字とテキストで代替表示します。

## GitHub Pages 公開手順
このリポジトリは静的サイトです。ビルド不要で公開できます。

1. Settings → Pages を開く
2. **Build and deployment → Source** を **「Deploy from a branch」** に変更
3. Branch を **`main`（または master）/ `(root)`** に設定して Save
4. 数十秒後、`https://<ユーザー名>.github.io/credit/` で公開されます

> 既に Source が「GitHub Actions」になっている場合も、上記2で
> 「Deploy from a branch」に切り替えれば静的HTMLがそのまま公開されます。
